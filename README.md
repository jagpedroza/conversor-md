# Conversor a Markdown

Aplicación de escritorio (Tkinter) que convierte archivos PDF, HTML y ZIP a Markdown usando [markitdown](https://github.com/microsoft/markitdown).

## Instalación

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Uso

```bash
python conversor_md.py
```
